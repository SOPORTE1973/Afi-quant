# Mesa Central

Aplicación web del motor centralizado: monitoreo del libro (M09), due diligence por fondo (M10) y constructor de presentaciones para clientes.

```bash
python apps/mesa_central/build.py
```

Publicada como artifact de claude.ai con las capacidades `db` (registro de presentaciones liberadas), `user` (quién liberó) y `downloads` (PPTX). Fuera de claude.ai la página funciona sin registro ni descarga; se puede presentar en pantalla.
